# Öffentlicher Ordner

Alle Werk-, Ausstellungs- und Porträtbilder werden jetzt über Sanity
verwaltet und automatisch über das Sanity CDN ausgeliefert — hier
müssen keine Bilder mehr manuell abgelegt werden.

Was optional trotzdem hierhin gehört:
- `favicon.ico`
- `icon-192.png`, `icon-512.png` (für das Web-App-Manifest)
